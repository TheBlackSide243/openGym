# openGym for Apple Watch (Plus, preview)

A watch-only SwiftUI app (watchOS 10+) that works next to openGym on the phone or in the browser:

- **Workout**: the workout in progress, read from your server: the exercise you are on, its sets
  with weight and reps, what comes next, the time and how many sets are done. With no workout
  running, the last one and your body weight.
- **Rest**: a rest timer with a tap on the wrist when it is over (a notification as well, so it
  arrives with the screen off), starting from your profile's rest time, ±15 s.
- **Heart**: records a strength workout in Apple Health and shows your heart rate and active
  energy live. While it runs the app stays awake with the screen off.
- It reads only: logging sets still happens on the phone or in the browser.

It talks to your openGym server with the same pairing as the phone app: in openGym, Settings →
Account → **Pair the mobile app**, then type the server address and the code on the watch. It
reads `GET /api/watch` (a few kilobytes, `api/watch.js`) every 10 seconds during a workout.

## Building

The project is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml`:

```sh
brew install xcodegen
cd watch && xcodegen generate
open OpenGymWatch.xcodeproj
```

The `Plus watchOS` workflow (`.github/workflows/plus-watch.yml`) does this on every push to
`plus` that touches `watch/`: it builds for the simulator and, unsigned, for a real watch, and
takes a screenshot of each page with sample data (`-demo`). The artifact `openGym-watch` holds
the screenshots and `openGym-watch-unsigned.zip`.

## Installing on a watch

An Apple Watch only runs signed apps, and HealthKit on the watch needs a paid **Apple Developer
Program** membership. With one:

1. Change `PRODUCT_BUNDLE_IDENTIFIER` in `project.yml` to an id of your own team and set
   `DEVELOPMENT_TEAM`.
2. Either open the project in Xcode on a Mac, pick your watch and Run; or upload a build to
   **TestFlight** and install it from the TestFlight app on the iPhone, which hands it to the watch.
